VFS and Storage

Logical address space

KEDDEH VFS may define large address universes without pretending every logical cell is physically provisioned.

10 TB substrate target

The server package treats 10 TB storage as a host-mounted volume boundary, not browser storage.

Readback

Mounted volumes require filesystem identity, capacity readback, path proofs and service consumption receipts.

Skills and Chat Execution

Authored skills are allowed as source. Chat execution requires installation or an exposed MCP/connector runtime. This site and repository package make that boundary explicit so KEDDEH skills can be packaged, tested and admitted without pretending source text is already privileged execution.

Squarespace Handoff

For immediate managed hosting, publish the Sites A/TXT records. For KEDDEH-operated nameservers, first provision public static IP hosts for ns1.keddeh.com and ns2.keddeh.com, launch the server package, verify UDP/TCP 53, then set registrar nameserver delegation and glue.
